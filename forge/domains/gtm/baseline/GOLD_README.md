# synthetic_gold.jsonl — GTM v0 Ground-Truth Corpus

## What this is

200 synthetic-but-grounded records for the `gtm@v1` schema. This is the **v0 fit**: calibration
numbers derived from this corpus are indicative, not buyer-validated. The buyer-CRM re-fit
(50-100 real labeled records) is the benchmark-call deliverable and supersedes this corpus.

## Record shape

Each line is a JSON object:

```json
{
  "source_doc_id": "synthetic_0001",
  "source_type": "linkedin_post | website_page | crm_note | call_transcript | email",
  "grounding_sources": ["<citation>", ...],
  "entities": [
    {
      "label": "<GtmLabel value>",
      "text": "<raw extracted span>",
      "normalized_value": "<canonical form or null>",
      "confidence": 0.87
    },
    ...
  ]
}
```

All `label` values validate against `GtmLabel` in `gtm_schema.py`.
All `confidence` values are in [0.0, 1.0].

## Grounding sources

Every record cites the real public taxonomies its ingredient data was drawn from:

| Ingredient | Source |
|---|---|
| Company names / domains | Curated list of real Crunchbase-listed / SEC-EDGAR public companies (as of 2024) |
| Industry labels | NAICS 2022 (census.gov/naics) |
| Funding stages | Crunchbase funding taxonomy (crunchbase.com/discover/funding_rounds) |
| Employee ranges | Salesforce/HubSpot standard headcount buckets |
| Titles / seniority | LinkedIn public job postings; ZoomInfo job-function taxonomy |
| Intent topics | Bombora B2B intent topic taxonomy (bombora.com/products/company-surge-data) |
| Pain points | r/sales and Sales Hacker public operator content |
| Qualification labels | MEDDPICC framework (public; multiple structured versions on GitHub/Notion) |

## Generation

Records were generated by `_gen_gold.py` with `SEED=42`. The committed `.jsonl` is the
deterministic output. Re-running the script with the same seed produces the identical file.

## Limitations

- **No operator validation.** No human reviewed these records against real deal data.
  The labels reflect the generator's logic, not operator judgment.
- **Distribution bias.** Companies drawn from a curated list of VC-backed tech companies.
  Under-represents SMBs, non-tech sectors, and international markets.
- **Confidence scores are synthetic.** Drawn from a uniform distribution within a range,
  not from a real calibrated model.

## v1 upgrade path

The benchmark call produces the real ground-truth corpus:
1. Buyer exports 50-100 CRM records (qualified / nurture / disqualified labeled)
2. Schema-forge maps fields to `GtmEntity` shape
3. The re-fit corpus replaces this file (or augments it) in `04_output/`
4. Calibration is re-run on the buyer corpus; ECE numbers are reported
